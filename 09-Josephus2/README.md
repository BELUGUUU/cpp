# 09 Josephus(Ⅱ) —— 动态数组

> 课程设计 OJ 题号 **2551**，问题 D：Josephus 问题(Ⅱ)。

## 题目

与 `08-Josephus1` 相同的报数出列问题，但要求用**顺序存储结构（动态数组，结构体封装）**实现。

## 思路

- 数组 `a[0..n-1]` 存人（结构体封装，含数组指针 / 容量 / 长度）；
- 报到 k 的人出列：其后元素整体**前移**覆盖（顺序表删除语义）；
- 用 `(pos + k - 1) % len` 直接算下一个出列下标，省掉逐步报数。

数据规模小，O(n²) 的前移不会超时。

## 输入样例

```
7 2
2 2
1 1
1000 37
```
