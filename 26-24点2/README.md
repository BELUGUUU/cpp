# 26 24 点(Ⅱ) —— 枚举全部表达式树

> 课程设计 OJ 题号 **1830**，问题 Z：24点游戏(Ⅱ)。

## 题目

给出 4 个数字，按题目规定的次序生成它们能构成的**所有表达式树**，每棵输出一行全括号表达式（4 个数字共生成 **7680** 个表达式）。

## 生成次序（严格按题目递归框架）

`gen(pool)`，num = pool 里数字个数：

- num == 1 → 叶子，直接把数字写出来；
- 否则 i 从 1 到 num-1（左子树的数字个数）：
  - 运算符按 `+ - * /` 依次枚举；
  - 把 pool 里 i 个数字分给左子树（**各子集按原位置次序枚举**），其余给右子树；
  - 左、右子树的每个表达式两两组合。

> 注：子集按"下标枚举"实现（不是按位掩码），保证与题目要求的输出顺序一致——这是 09-16 修过的坑。

## 输入样例

```
1 2 3 4
```
