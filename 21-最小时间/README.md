# 21 最小时间（全源最短路）

> 课程设计 OJ 题号 **1075**，问题 U：最小时间。

## 题目

给定铁路网络（边权为通行时间），求"从城市 1 出发，多少时间内能够到达**所有**城市"。

## 思路

只要最远的城市能到达，其余城市自然都能到达，所以：

**答案 = max{ dist(1, j) | j = 1..n }**

- 输入只给邻接矩阵**下三角**，`x` 表示无直连 → 补全为无穷大；
- n ≤ 100，直接 **Floyd** 求全源最短路；
- 取第 1 行的最大值。

## 输入细节

多组数据直到文件结束；每条边权**读作字符串**（因为可能是 `'x'`）。

## 输入样例

```
5
50
30 5
100 20 50
10 x x 10
```

## 文件

| 文件 | 说明 |
|---|---|
| `main.cpp` | 补全邻接矩阵 + Floyd |
| `sample_in.txt` | 样例输入 |

## 本地验证

g++ -O2 -std=c++11 -Wall -o main.exe main.cpp
