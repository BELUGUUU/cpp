# 04 线性表 RDD 操作 —— ADT 设计与双实现

> 课程设计 OJ（cid=3775）问题 G：线性表 R/D 操作。一道"一题多解 + 复杂度实验"的大题。

## 题目

对一个线性表反复执行操作串 S（只含 `R` 逆转整表、`D` 删除表中第一个元素）：

- 对**空表**执行 `D` → 输出 `error`；
- 操作全部执行完后输出最终表（`[a,b,c]` 形式）。

约束：|S| ≤ 100000，n ≤ 100000，元素值 1..100。

**题目要求**：(1) 设计一个 ADT；(2) 至少实现两个版本，其中一种使用**双向链表**。

## 核心技巧：`rev` 逆转标志

`R` 若老实逐结点交换 prev/next，单次 O(n)，最坏 O(n·|S|) = 10¹⁰ 必 TLE。正确做法是用布尔量 `rev` 记录"逻辑顺序是否与物理顺序相反"：

| 操作 | 双向链表版 | 顺序表版 |
|---|---|---|
| `R` | `rev = !rev`（O(1)） | 同左 |
| `D` | rev 假删物理头 / 真删物理尾（O(1)） | rev 假 `++lo` / 真 `--hi`（O(1) 窗口收缩） |

**为什么必须用双向链表**：rev 为真时"表中第一个元素"落在物理尾，删完要把 tail 指回其**前驱**——双向链表靠 prev 一步到位，单链表尾删退化 O(n)。

## 实验结论（03-复杂度对比实验）

规模 ×3（4000→12000）时：

- 双链+标志 / 顺序+窗口：增长 **2.8 / 2.3 倍**（线性，应 ≈3）
- 双链+物理逆置 / 顺序+物理删除：增长 **11.0 / 11.3 倍**（二次，应 ≈9）

外推到 OJ 上限 n = |S| = 10⁵，物理逆置类做法需要约 10¹⁰ 次操作，必然 TLE。
