# 04-02 顺序表实现 —— 线性表 R/D 操作

> 线性表 R/D 操作的版本二：**顺序表（数组）+ 下标窗口 + 逆转标志**。与版本一共用同一个 ADT 接口 `LinearList`，只换存储结构。

## 实现要点

顺序表"删除第一个元素"按教科书要移位覆盖 O(n)，全删一遍 O(n²) = 10¹⁰ 超时。这里**不搬元素**，维护下标窗口 `[lo, hi]` 表示当前表在数组中的有效区间：

| 操作 | 动作 | 复杂度 |
|---|---|---|
| build | `lo = 0, hi = n-1` | O(n) 一次拷贝 |
| `R` | `rev = !rev` | O(1) |
| `D` | rev 假 `++lo` / 真 `--hi` | O(1) |
| empty | `lo > hi` | O(1) |

删掉的元素原地不动，只在最后输出 `[lo,hi]` 区间；lo/hi 单调收缩，总位移 O(n)。

## 与双向链表的取舍

- **顺序表**：内存连续、常数小、随机访问快；中间插删要搬元素、容量固定，删除靠"窗口/懒惰删除"绕开搬运。
- **双向链表**：任意位置插删 O(1)、按需分配；但每结点多两个指针、缓存不友好、常数更大。

两种在本题都达到 O(|S| + n)，差别只在运行常数（见 `../03-复杂度对比实验/`，顺序+窗口绝对耗时最小）。
