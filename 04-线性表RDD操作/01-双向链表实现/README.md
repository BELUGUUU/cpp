# 04-01 双向链表实现 —— 线性表 R/D 操作

> 线性表 R/D 操作的版本一：**双向链表 + 逆转标志**。题目指定必须包含的双向链表版。

## 实现要点

- 结点存 `prev/next/value`，`head_/tail_` 双端指针 + 布尔量 `rev_`。
- `R`：`rev_ = !rev_`，O(1)，**绝不真的逐结点逆转**（单次 O(n)，|S| ≤ 10⁵ 会 TLE）。
- `D`：`rev_` 为假删物理头、为真删物理尾，O(1)。空表返回 false → 输出 `error`。
- 析构与遍历都按 `rev_` 决定方向；析构用**迭代释放**（顺物理链走），深链也不爆栈。

## 为什么必须双向

rev 为真时，逻辑首元素在物理尾结点，删除后要把 tail 指回它的**前驱**——双向链表 `prev` 一步到位；单链表只能从头扫，尾删退化 O(n)。这是本题选双向链表的实质原因，不只是形式要求。

## 复杂度

建表 O(n)；扫描操作串 O(|S|)；输出 O(n)。整体与 |S|、n 成线性。
