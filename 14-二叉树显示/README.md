# 14 二叉树的创建和显示

> 课程设计 OJ 题号 **1826**，问题 P：二叉树的创建和文本显示。

## 题目

输入二叉树的**先序遍历序列**（`#` 表示空子树），以树形文本把二叉树"左旋 90°"打印出来。

## 思路

- **建树**：读先序序列递归建树，`#` 即空子树（运算符/数字/字母通用）。
- **显示**：递归打印——右子树在上、根居中、左子树在下；每层比上一层**多缩进 4 个空格**，结点值本身占 4 列对齐。

## 输入样例

```
A ST C # # D 10 # G # # F # # #
4 2 1 # # 3 # # 5 # 6 # #
```

## 文件

| 文件 | 说明 |
|---|---|
| `main.cpp` | 先序建树 + 左旋 90° 树形打印 |
| `sample_in.txt` | 样例输入 |

## 本地验证

```bash
g++ -O2 -std=c++11 -Wall -o main.exe main.cpp
./main.exe < sample_in.txt
```
