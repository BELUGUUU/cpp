# 13 中缀转后缀

> 课程设计 OJ 题号 **1823**，问题 O：中缀表达式转后缀表达式。

## 题目

输入中缀表达式（只含单字母变量和 `+ - * /`、括号），输出等价的后缀表达式（逆波兰式）。

## 思路

经典**调度场（Shunting-yard）算法**：

- 操作数 → 直接输出；
- 运算符 → 弹出栈顶所有优先级 ≥ 当前运算符的运算符后再入栈（同级左结合）；
- `(` → 入栈；`)` → 弹到最近的 `(` 为止；
- 结束 → 弹空栈。

## 输入样例

```
X+A*(Y-B)-Z/F
A+B
(A+B)*C/D
```

## 文件

| 文件 | 说明 |
|---|---|
| `main.cpp` | 调度场算法 |
| `sample_in.txt` | 样例输入 |

## 本地验证

```bash
g++ -O2 -std=c++11 -Wall -o main.exe main.cpp
./main.exe < sample_in.txt
```
