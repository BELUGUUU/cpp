# 28 24 点(Ⅳ) —— 等价去重统计解法数

> 课程设计 OJ 题号 **2007**，问题 AB：24点游戏(Ⅳ)。

## 题目

给出四个数字，求有多少种**互不相同**的解法能算出 24，并按 `26-24点2` 的枚举顺序输出每个解的**第一个**表达式。

难点在"不同解法"的判定，题目给了 **6 条等价规则**：

1. 加法和乘法满足交换律、结合律
2. `a-b = a+(-b)`
3. `a/b = a*(1/b)`
4. `a*1 = 1*a = a/1 = a`
5. `a/a = 1`
6. `a+0 = a-0 = a`

## 思路：表达式规范化

把每个表达式规范化成一个字符串，规则等价的表达式规范化后完全相同，用集合去重：

- **加/减**：展平成「项的集合」，`-b` 记作 `N(b)`，去 0，排序；
- **乘/除**：展平成「因子的集合」，`b` 的倒数记作 `I(b)`，去 1 和 `I(1)`，再把 `(x, I(x))` 这样的互逆对消掉，排序；
- **数值用精确分数**（分子/分母）表示，除法不做浮点近似。

于是「不同解」= 规范化字符串不同；每个等价类取枚举顺序里第一个表达式输出。

> 注：负零 `N(0)` 要消去——这是 09-16 补过的坑。

## 输入样例

```
1 3 5 7
```
