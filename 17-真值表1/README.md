# 17 真值表(Ⅰ) —— 词法分析

> 课程设计 OJ 题号 **2257**，问题 H：真值表(Ⅰ)。真值表系列第一阶段。

## 题目

给定逻辑表达式，只做**词法分析**：

- 切分成词(token)序列并输出；
- 提取**字母序变量表**；
- 输出变量取值组合表。

## 思路

- 词法切词：单字符 token（变量、`^ ! ( )`）直接切，多字符 token（`->`、`<->`、`||`）向前看合并。
- 变量去重后**按字母序**排列输出。
- 取值组合从全 1 递减到全 0（为 `18-真值表2` 的求值做准备）。

## 输入样例

```
p
p->q
p||q
p^(q^r)
```

## 文件

| 文件 | 说明 |
|---|---|
| `main.cpp` | 词法切词 + 变量表 |
| `sample_in.txt` | 样例输入 |

## 本地验证

```bash
g++ -O2 -std=c++11 -Wall -o main.exe main.cpp
./main.exe < sample_in.txt
```

同题族：`18`（求值）、`05`（错误定位完整版）。
