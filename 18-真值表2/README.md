# 18 真值表(Ⅱ) —— 语法树求值

> 课程设计 OJ 题号 **2258**，问题 I：真值表(Ⅱ)。真值表系列第二阶段。

## 题目

给定逻辑表达式（**保证正确**），输出完整真值表：

- 表头 = 字母序变量 + 原表达式；
- 每行 = 各变量的一种取值 + 该行表达式的值。

## 思路

1. 词法切词（同 `17-真值表1`）；
2. **递归下降**建立语法树，优先级从低到高：`<->` → `||` → `^` → `!`（括号最高），每层一个函数；
3. 变量组合从全 1 递减到全 0，逐行在语法树上求值。

## 输入样例

```
p
p->q
p||q
```

## 文件

| 文件 | 说明 |
|---|---|
| `main.cpp` | 递归下降 + 逐行求值 |
| `sample_in.txt` | 样例输入 |
