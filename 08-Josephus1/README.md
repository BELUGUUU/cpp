# 08 Josephus(Ⅰ) —— 循环链表

> 课程设计 OJ 题号 **1719**，问题 C：Josephus 问题(I)。

## 题目

n 个人围成一圈从 1 开始报数，报到 k 的人出列，下一人重新从 1 报数，直到剩最后一人。输出出列顺序（或最后剩下的人，见 OJ 原题）。

## 思路

**不带头结点的循环链表**直接模拟报数：

- 建循环链表 1..n；
- 沿链走 k-1 步，删除当前结点；
- 重复直到链表为空。

数据规模小（n ≤ 1000 级），模拟即可。

## 输入样例

```
7 2
2 2
1 1
1000 37
```

多组 `n k`，`0 0` 或 EOF 结束

## 文件

| 文件              | 说明     |
| --------------- | ------ |
| `main.cpp`      | 循环链表模拟 |
| `sample_in.txt` | 样例输入   |

## 本地验证

```bash
g++ -O2 -std=c++11 -Wall -o main.exe main.cpp
./main.exe < sample_in.txt
```

同题族：`09`（动态数组版）、`10`（k=2 公式版）、`11`（通用递推版）。
