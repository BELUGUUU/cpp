# 16 表达式树的值

> 课程设计 OJ 题号 **1828**，问题 R：表达式树的值。

## 题目

输入一棵表达式树的先序序列（`#` 为空子树），输出 `(全括号表达式)=值`。

## 思路

在 `15-表达式树输出` 的基础上，递归返回时**同时**做两件事：

- 拼全括号中缀式（左式 op 右式）；
- 按运算符递归求左右子树的值。

最后输出 `(表达式)=整数值`。

## 输入样例

```
+ 13 # # * 5 # # 9 # #
* + 13 # # 5 # # 9 # #
```

## 文件

| 文件 | 说明 |
|---|---|
| `main.cpp` | 建树 + 求值一体化 |
| `sample_in.txt` | 样例输入 |

## 本地验证

```bash
g++ -O2 -std=c++11 -Wall -o main.exe main.cpp
./main.exe < sample_in.txt
```

相关：`15`（输出部分）、`27`（24 点按精确分数求值）。
