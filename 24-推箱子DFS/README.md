# 24 推箱子 · DFS 版

> 课程设计 OJ 题号 **1982**，问题 X：推箱子游戏（深度优先搜索版本）。

## 题目

与 `23-推箱子BFS` 相同的地图与规则，但按题目要求用 **DFS**：不要求最少步数，而是输出 DFS 实际走出的那一条**移动序列**（`U/R/D/L` 组成的字符串）；无解输出 `-1`。

## 思路

状态仍是「玩家位置 + 箱子位置」，每到一个状态按 **上(U)、右(R)、下(D)、左(L)** 的顺时针方向依次尝试，前一个方向失败才试下一个；一旦箱子被推到目的地立即返回。

走过的状态用四维数组标记，避免反复绕圈。

## 与 BFS 版的区别

- BFS 求的是**最少步数**（逐层扩展）；
- DFS 输出的是**搜索顺序意义下的第一条可行路径**，步数未必最少——这正是两题分开出题的考点。

## 输入样例

```
6 6
...#..
......
#*##..
..##.#
..X...
.@#...
3 3
X..
#*.
@..
```
