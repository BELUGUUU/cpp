# 25 24 点(Ⅰ) —— 表达式树判定

> 课程设计 OJ 题号 **1829**，问题 Y：24点游戏(Ⅰ)。

## 题目

输入一棵表达式树的**先序遍历序列**（`#` 表示空结点），判断这棵树的值能不能算出 24：能就输出全括号表达式并接上 `=24`，否则输出 `NO`。

## 思路

1. **先序序列递归建树**：读一个记号，`#` 是空子树；运算符先递归左子树、再右子树；数字是叶子。
2. 递归返回时顺便拼**全括号中缀式**：`out = "(" + 左式 + op + 右式 + ")"`。
3. 值用 **double** 计算：表达式来自真实 24 点场景，除法要按实数比较（整数除法会误判），与 24 的误差小于 1e-9 认为相等。

## 输入样例

```
+ + + 6 # # 6 # # 6 # # 6 # #
- - * 6 # # 6 # # 6 # # 6 # #
* * 1 # # 2 # # * 1 # # 2 # #
```

## 文件

| 文件 | 说明 |
|---|---|
| `main.cpp` | 建树 + double 求值 |
| `sample_in.txt` | 样例输入 |

## 本地验证

```bash
g++ -O2 -std=c++11 -Wall -o main.exe main.cpp
./main.exe < sample_in.txt
```

同题族：`26`（枚举全部表达式）、`27`（第一个 =24）、`28`（去重统计解法数）。
