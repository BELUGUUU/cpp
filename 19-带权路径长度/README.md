# 19 带权路径长度（WPL）

> 课程设计 OJ 题号 **1832**，问题 S：带权路径长度。

## 题目

给 n 个叶子的权值，求对应**哈夫曼树**的带权路径长度 WPL，对 10⁹+7 取模输出。

## 思路

**哈夫曼树的构造过程本身就在累加 WPL**：每次取出两个最小权值合并，把"合并后的权值"累加到总和，合并 n-1 次后总和恰好就是整棵树的 WPL——不必显式建树。

用小根堆（优先队列）维护，复杂度 **O(n log n)**。

## 溢出处理

n ≤ 10⁵、权值 ≤ 10⁹ 时 WPL 量级约 4.4×10¹⁵，`long long` 足够；最后对 1000000007 取模输出。

## 输入样例

```
4
7 5 2 4
8
5 29 7 8 14 23 3 11
```
