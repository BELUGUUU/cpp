# 11 Josephus(Ⅳ) —— 通用递推 + 跳跃优化

> 课程设计 OJ 题号 **1721**，问题 F：Josephus 问题(Ⅳ)。

## 题目

通用 k（k ≤ 100）的 Josephus 问题，**n < 2³¹**：

- 纯模拟 O(n·k) 或每组 O(n) 递推都会超时，需要跳跃优化。

## 思路

**标准递推**：f(1) = 0，f(i) = (f(i-1) + k) % i，答案 = f(n) + 1。

**免取模跳跃优化**：当 f + (k-1)·t < i 时，接下来 t 步递推都不用取模，可以一次跳完——把 t 步合并成一次加法再补取模。当 k 很小、n 很大（如 n = 2³¹-1, k = 2）时，从 O(n) 降到近似 O(n/k) 段数，实测通过。

## 输入样例

```
7 2
2 2
1 1
1 100
1000000000 100
2147483647 2
```

每组 `n k`，输出幸存者编号。
