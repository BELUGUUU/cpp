# C++ 数据结构课设

湖南科技大学《数据结构》课程设计 OJ 题解，两道大题、共 5 份实现，全部在 GCC 16.2 (MinGW-w64) 下以 `g++ -O2 -std=c++11 -Wall` 编译，零告警。

## 题目一：单词检查（拼写检查器）

字典维护 + 编辑距离为 1 的修改建议，同一道题用三种结构实现，做复杂度对比：

| 目录 | 实现 | 单次查询 | 总复杂度 |
|---|---|---|---|
| `01-顺序表实现` | 顺序表 + 单次编辑判定 | O(n·L) | O(m·n·L) |
| `02-二叉排序树实现` | BST（迭代插入/后序遍历，防退化爆栈）+ index 还原字典序 | O(L·log n) | O(m·L²·log n) |
| `03-哈希实现` | 手写哈希（多项式 vs ELF）+ 线性探测/链地址双策略 | O(L) 期望 | O(m·L) |

n ≤ 500000（字典），m ≤ 200（待查词），L ≤ 15（词长）。

### 哈希实验结论（`03-哈希实现/benchmark_result.txt`）

- **ELF hash 低位随机性弱**：表容量取 2 的幂、`(h & mask)` 只用低位时，ELF 在线性探测下平均探测 336.84 次，补一次终混后降到 1.42——哈希函数必须与取模方式配套。
- 朴素累加哈希 2 万词规模下线性探测平均探测 18934 次，差好哈希 4 个数量级。
- 链地址法对装填因子不敏感；线性探测在 α→1 时发生一次聚集，探测长度急剧上升。

## 题目二：线性表 R/D 操作

ADT 设计 + 双实现（共用纯虚接口 `LinearList`，换实现只改一行）：

- `04-线性表RDD操作/01-双向链表实现`：双向链表 + 逆转标志
- `04-线性表RDD操作/02-顺序表实现`：数组 + `[lo,hi]` 下标窗口 + 逆转标志

**核心技巧**：`R` 不真逆置（单次 O(n)，|S|≤1e5 必 TLE），用 `rev` 标志让 R/D 都成为 O(1)；`D` 按 rev 删物理头或物理尾——这正是必须用双向链表的原因（rev 为真时删物理尾需 O(1) 拿前驱）。

### 复杂度实验（`03-复杂度对比实验/benchmark_result.txt`）

规模 ×3（4000→12000）时：标志法增长 2.8 倍（线性），物理逆置法增长 11.0 倍（二次）。
