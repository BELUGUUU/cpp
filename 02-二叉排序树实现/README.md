# 02 二叉排序树实现 —— 单词检查(Ⅱ)

> 课程设计 OJ（cid=3775）问题 L：单词检查·二叉排序树实现。同一道题的第二个数据结构版本。

## 题目

与顺序表版（`01-顺序表实现`）相同的拼写检查任务，但用**二叉排序树（BST）维护字典，并且第一行要输出 BST 的后序遍历**（每个单词后跟一个空格，最后一个也不例外），之后再逐个检查待测单词并输出建议词。

## 思路

- **结点只存单词在 pool[] 中的下标 idx**，不存第二份字符串；该下标同时是单词在字典文件中的出现次序，命中结果按 idx 升序排序即还原"字典出现先后次序"。
- **建议词生成**：对 w 枚举三种编辑操作——每个位置插入 'a'~'z'、删除一个字符、替换一个字符，共约 53L 个候选；每个候选到 BST 中检索，命中即为建议词。
- 按字典序 strcmp 插入，左小右大。

## 细节

1. **插入与后序遍历都用迭代实现**（后序用双栈法）：字典若按字典序给出，BST 会退化成 n 层的链，递归版极易栈溢出。
2. 后序遍历每个词后**都跟一个空格**，最后一个也不例外（题目明确要求）。

## 复杂度

建树 O(n·L·log n)（平均）；后序 O(n)；单次查询 O(L²·log n)；总体 **O(n·L·log n + m·L²·log n)**。  
最坏（有序输入）BST 退化为链，与顺序表同级。
