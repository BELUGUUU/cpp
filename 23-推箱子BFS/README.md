# 23 推箱子 · BFS 版

> 课程设计 OJ 题号 **1981**，问题 W：推箱子游戏（广度优先搜索版本）。

## 题目

N×M 地图（0 < N, M ≤ 12）：`.` 空地、`X` 玩家、`*` 箱子、`#` 障碍、`@` 目的地。玩家可四方向移动，推箱子时箱子同向移动一格。求把箱子推到目的地的**最少步数**；无解输出 `-1`。

## 思路

把**「玩家位置 + 箱子位置」**看成一个状态，玩家每走一步是一次状态转移，**BFS 逐层扩展**——第一次让箱子落到目的地时走过的层数就是最少步数。

状态总数 = 12×12×12×12 ≈ 2 万，四维 visited 数组即可。

状态转移（玩家朝向 dr/dc）：

1. 目标格越界或是墙 → 非法；
2. 目标格有箱子 → 箱子要推到再前面一格，那格必须不越界、不是墙、无别的箱子；玩家和箱子一起动；
3. 目标格是空地/目的地 → 只有玩家动。

## 输入样例

```
6 6
...#..
......
#*##..
..##.#
..X...
.@#...
```
