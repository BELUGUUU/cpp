# 29 Repairing a Road（OJ 1044）

> 课程设计 OJ 题号 **1044**，问题：Repairing a Road（与 `22-修路` OJ 2010 为同题不同题号的两个版本）。

## 题目

C 个路口、R 条双向道路，第 i 条路有正常通行时间 vᵢ 和修理参数 aᵢ。你从路口 1 出发的同时，朋友挑**恰好一条**路修 t 个时间单位（t 为非负实数），修好后这条路的通行时间变成 `vᵢ / aᵢ^t`；修理期间不能通过这条路。求从 1 到 C 的最短总时间。

## 思路

1. 最优方案一定是「1 →u 走最短路，跨过被修的路 (u,v)，再从 v→C 走最短路」。**Floyd** 求全图最短路 d[][]，枚举每条路、每个方向。
2. 设到达 u 的时刻 A = d[1][u]，跨这条路的耗时：

   ```
   f(t) = max(A, t) + v·a^(-t)
   ```

   到得早就要等修完（max 里的 t），到得晚直接走。

   - **t ≤ A** 段：`A + v·a^(-t)` 单调递减，最小值在 t = A；
   - **t ≥ A** 段：`f'(t) = 1 − v·ln a·a^(-t)`，极值点 `t* = ln(v·ln a)/ln a`（当 `v·ln a > 1`），最小值 = `t* + 1/ln a`；
   - a = 1 时修了也没用，取 t = 0，耗时 A + v。
3. 答案 = min{ d[1][u] + f_min + d[v][C] }，再与「不修路直接走」的 d[1][C] 取小。

复杂度：Floyd O(C³) + 枚举 O(R)，C ≤ 100、R ≤ 500，非常宽松。

## 输入细节

多组数据，每组第一行 `C R`，随后 R 行 `u v vᵢ aᵢ`（实数），`C = R = 0` 结束；读入时把逗号换成空格，兼容逗号分隔版本。输出每组一行，保留三位小数。
