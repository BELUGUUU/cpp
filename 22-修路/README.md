# 22 修路（2010 省赛 Repairing a Road）

> 课程设计 OJ 题号 **2010**（2010 年省赛），问题 V：修路。

## 题目

C 个路口、R 条双向路，从 1 号走到 C 号。每条路有原通行时间 v 与修复系数 a。你只有一次机会请朋友修**一条**路：他修 t 个单位时间后，这条路的花费变成 `v * a^(-t)`（修得越久越快，但修的时候不能走）。求到达 C 的最早时间。

## 思路（凸函数解析最优）

在修边 (u,v) 并沿 u→v 走的情况下，总时间：

```
f(t) = max(d1[u], t) + v·a^(-t) + d2[v]
```

其中 d1 = 以原时间算的 1 出发的最短路，d2 = v 到 C 的最短路。

- **t ≤ d1[u]**：f 随 t 递减，最优取 t = d1[u]（等修完再走）；
- **t > d1[u]**：g(t) = t + v·a^(-t) 是凸函数，解析求导 `g'(t)=0 → a^(-t) = 1/(v·ln a) → t* = ln(v·ln a)/ln a`，若 t* > d1[u] 则取 t*。

枚举每条边两个方向取最小，再与"完全不修"的 d1[C] 比较。

## 输入

多组数据，每组首行 `C R`（2 ≤ C ≤ 100，1 ≤ R ≤ 500），随后 R 行 `x y length a`；以 `0 0` 结束。输出最小时间，保留 3 位小数。
