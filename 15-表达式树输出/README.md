# 15 表达式树的创建与输出

> 课程设计 OJ 题号 **1827**，问题 Q：表达式树的创建与输出。

## 题目

输入一棵表达式树的**先序遍历序列**（`#` 表示空子树），输出它对应的**全括号中缀表达式**。

## 思路

- 先序序列递归建树：读一个记号，`#` 是空子树；是运算符就先递归左子树、再递归右子树；是数字就是叶子。
- 递归返回时拼串：`out = "(" + 左式 + 运算符 + 右式 + ")"`；叶子直接输出数字。

## 输入样例

```
+ 13 # # * 5 # # 9 # #
* + 13 # # 5 # # 9 # #
```

对应 `(13+(5*9))` 等。

## 文件

| 文件 | 说明 |
|---|---|
| `main.cpp` | 先序建树 + 全括号中缀输出 |
| `sample_in.txt` | 样例输入 |

## 本地验证

```bash
g++ -O2 -std=c++11 -Wall -o main.exe main.cpp
./main.exe < sample_in.txt
```
