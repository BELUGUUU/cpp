# 07 复杂度分析(Ⅱ)

> 课程设计 OJ 题号 **1723**，问题 B：复杂度分析(Ⅱ)。

## 题目

分析如下 while 循环 `printf` 的执行次数，以及循环结束后 `i+j+k` 的值：

```c
i=1;
while(i++<n){ j=1; while(j++<i){ k=1; while(k++<j) printf("\n"); } }
```

注意 `i++<n` 是先比较后自增，与 for 循环版（`06-复杂度分析1`）不同。

## 结论

- **printf 次数** = Σ_{t=1}^{n-1} t(t+1)/2 = **n(n-1)(n+1)/6**（求和公式）。
- **循环结束后 i+j+k = 3(n+1)**（i=n+1 时比较失败并自增，j、k 同理各自多走一步）。

## 输入样例

```
3
2
1
3000
```
