# 20 自来水管道（最小生成树）

> 课程设计 OJ 题号 **1074**，问题 T：自来水管道。

## 题目

P 个供水点、R 条可铺设路径（成本各异），要求任意两点直接或间接连通且总成本最低——即求**最小生成树（MST）**的边权和。

## 思路

**Kruskal**：所有边按成本升序排序，依次取边，两端点不在同一集合就合并（并查集），累加成本；合并 P-1 次即得最小总成本。并查集用**路径压缩 + 按秩合并**，整体 O(R log R)。

## 输入细节

- 多组数据，每组第一行 `P R`；**P=0 结束**（此时没有 R）。
- 组与组之间可能有空行，scanf 读整数自动跳过空白。
- P=1 时没有边，答案为 0。

## 输入样例

```
2 3
1 2 37
2 1 17
1 2 68
...
0
```

注意同一对点之间可能有多条边，也可能有重边方向相反，排序去重交给 Kruskal 天然处理。
