# 05 真值表(Ⅲ) —— 词法·语法·错误定位

> 课程设计 OJ 题号 **2259**，问题 J：真值表(Ⅲ)。真值表系列的第三阶段（合并实现）。

## 题目

给定逻辑表达式，三个阶段合并：

1. **词法分析**：把表达式切分为词(token)，非法残缺符号立即定位报错；
2. **求值列**：递归下降建立语法树，按变量取值组合逐行求值；
3. **错误检测**：词法错误优先于语法错误，报出第一个错误所在位置。

运算符优先级从低到高：`<->` → `||` → `^` → `!`（括号最高），除双向蕴含外均左结合。

## 关键设计

1. **词法与语法严格分两阶段**：先整体切词，任一位置出现词法错误就地抛出；全部词法合法后才进入语法分析——"词法错误优先于语法错误"自然成立。
2. **位置语义**：读到末尾仍缺词（含括号未闭合）→ 位置 = 长度+1；多余/非法词 → 该词的 1 起始位置。
3. 递归下降每层优先级一个函数，结构清晰可扩展。

## 输入样例（sample_in.txt）

```
a->b->
p^q
a->b c->d
a<-b
(a^b)->!c
```
