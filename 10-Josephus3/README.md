# 10 Josephus(Ⅲ) —— k=2 递推公式

> 课程设计 OJ 题号 **1720**，问题 E：Josephus 问题(Ⅲ)。

## 题目

k = 2 的 Josephus 问题，但 **n < 2³¹**——循环链表 / 数组模拟都会超时，必须用公式。

## 结论

设 n = 2^m + L（0 ≤ L < 2^m），即 2^m 是不超过 n 的最大 2 的幂，则最后剩下的人编号：

```
J(n) = 2L + 1
```

推导要点：每过一轮人数减半，幸存者编号在偶数子问题里恰好翻倍加一。

## 输入样例

```
7
2
1
3
8
1000000000
```

每组一个 n，输出幸存者编号。

| `sample_in.txt` | 样例输入 |
