# 12 后缀表达式求值

> 课程设计 OJ 题号 **1824**，问题 N：后缀表达式求值。

## 题目

输入后缀表达式（逆波兰式），操作数与运算符以空格分隔，求值。`@` 为表达式结束符。

## 思路

经典**操作数栈**法，逐字符扫描：

- 是数字 → 完整读入多位数后进栈；
- 是运算符 → 弹两个数（先弹的是右操作数）计算，结果回栈；
- 遇 `@` 结束，栈顶即答案。

**细节**：`*8` 这类运算符与操作数粘连的写法，逐字符扫描可以自然分开（读到 `*` 即当运算符处理，`8` 另起一个数），不需要先切词。

## 输入样例

```
14  3 20 5 / *8 - + @
3 4 + @
```

## 文件

| 文件 | 说明 |
|---|---|
| `main.cpp` | 操作数栈求值 |
| `sample_in.txt` | 样例输入 |

## 本地验证

g++ -O2 -std=c++11 -Wall -o main.exe main.cpp
